# 🏦 Venkatesh Multistate Bank - Responsive Landing Page

A modern and responsive **banking website landing page** developed for Venkatesh Multistate Bank.

The website is designed in **Marathi** and presents information about deposit schemes, loan services, accounts, digital banking facilities, and customer services through a clean and responsive interface.

## ✨ Key Features

* 📱 Responsive navigation bar
* 🇮🇳 Marathi-language user interface
* 🔽 Dropdown navigation menus
* 💰 Deposit schemes (ठेव योजना)
* 🏦 Account information (खाते)
* 💳 Loan services (कर्ज योजना)
* 📱 Smart and Digital Banking information
* 🔄 Promotional image carousel
* 💳 Banking service cards
* 🪪 Aadhaar Banking information
* 💳 Debit Card information
* 📲 QR Code payment information
* 🎥 Embedded YouTube videos
* 📰 Informational content/blog sections
* 📱 Mobile application promotion section
* 📩 Customer contact form
* 🔗 Footer with useful links and social media icons
